如何在正式文章中启用这些样式？

只需在任意 _posts/*.md 顶部的 Frontmatter 中按需添加以下字段即可（不加则为默认纯文字紧凑样式）：

```yaml --- layout: post title: 文章标题 date: 2026-11-25 description: 可选的一行简短副标题 thumbnail: assets/img/HEM.jpg # 可选：右侧小缩略图 bg_img: assets/img/quant2026.png # 可选：柔和渐变背景图条 bg_color: warm # 可选：预设 accent / warm / cool / sage / neutral，或任意 CSS 颜色如 "#f8f5ff" --- ```
